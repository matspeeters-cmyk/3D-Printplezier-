3D PRINTPLEZIER - WEBSITEBESTANDEN VOOR GITHUB PAGES

Inhoud:
- index.html
- data/products.json

Upload/vervang BEIDE bestanden in de hoofdmap van je GitHub-repository:
1. index.html in de hoofdmap (naast README.md / andere bestanden)
2. products.json in de map data (data/products.json)

Commit changes. GitHub Pages publiceert daarna de wijzigingen.

Let op:
- De productfoto's zijn nog niet toegevoegd; producten tonen voorlopig een emoji als tijdelijke afbeelding.
- Prijzen zijn indicatieve voorstellen.
- Controleer per MakerWorld-model de licentie en commerciële verkooprechten voordat je prints verkoopt.
- Vul je eigen WhatsApp-nummer in de bestelcode in als je bestellingen via WhatsApp wilt ontvangen.
